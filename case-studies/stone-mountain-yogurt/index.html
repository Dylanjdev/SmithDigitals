SEO Redesign + Twilio Automation

From outdated site to growth-ready digital storefront.

Stone Mountain Yogurt had an older website that no longer reflected the brand and did not support strong discoverability. The rebuild focused on search visibility, modern UX, and direct customer communication through SMS automation.

After

Automation

Custom Twilio API

The challenge

Modernize the site and improve discoverability.

The previous website lacked structure for search and did not provide a strong customer experience across devices. Stone Mountain Yogurt needed a cleaner site architecture and a way to engage customers beyond the website itself.

What I built

A new SEO foundation with direct SMS automation.

Redesigned the full website experience with a faster, modern, mobile-first layout.

Implemented SEO-focused page structure and metadata to improve search performance.

Developed a customized Twilio API integration for automated customer text messaging.

Aligned content and conversion flow so visitors can quickly find info and take action.

Result

Stronger visibility and better customer communication.

Stone Mountain Yogurt now has a modern, SEO-optimized website that supports long-term local search growth, plus a custom Twilio-powered texting workflow that helps the business stay connected with customers in real time.

Behind the build

The decisions were shaped by the business, not by a template.

Stone Mountain Yogurt was working from an older website that no longer represented the business or supported the experience customers needed. The rebuild had to improve the public storefront while also creating a more direct communication channel after the visit.

Design and strategy decisions

What made this project specific to the client.

01

Start with structure

A clearer information architecture gives search engines and customers a more reliable understanding of the business, its offer, and its important pages.

02

Connect discovery to retention

The website handles first-touch information while the Twilio-powered workflow supports direct customer communication beyond the page visit.

03

Make mobile the baseline

The experience was rebuilt for the small screen first, where local customers are often checking information while making plans.

04

Keep automation purposeful

The custom messaging workflow supports a business communication need rather than adding automation as decoration.

How the work came together

Strategy, experience, and implementation in one loop.

The project moved from a legacy-site diagnosis into a coordinated rebuild: content and page structure first, interface and responsive behavior next, then the custom integration that extended the relationship beyond the website.

A redesign can create more value when it addresses the system around the website. Better pages improve discovery, but thoughtful automation can help the business stay connected after a customer leaves the browser.
